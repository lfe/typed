## Standing lesson (for future milestones)

**Generated code vs. runtime support.** Only *per-type / per-program* logic should be
generated (validators, guards, lowered constructors). *Fixed, type-agnostic* helpers
(`render-type-error`, future formatters, decoders' shared plumbing) belong in a **hand-written
runtime-support module** compiled normally — where module-qualified calls and library
functions are trivial. Reaching for codegen for a type-agnostic helper drags in
form-emission problems that don't need to exist.
