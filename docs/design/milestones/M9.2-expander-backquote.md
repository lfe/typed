# Milestone M9.2 — Expander Phase 1a: Backquote + Core-Form Recursion (Rust port)

> **Goal:** port LFE's backquote expander and the core-form structural recursion to Rust,
> faithfully (validated against the M9.1 oracle goldens), and **run expansion over ALL
> forms emitted to `lfe_codegen`** — retiring the ad-hoc `qq_expand` and fixing the
> plain-form gap. **Builds on:** M9.1 (oracle + corpus + conventions, closed).
> **Design:** [05-lfe-expander-port.md](../05-lfe-expander-port.md) (Tier 1) +
> [06-expander-conventions.md](../06-expander-conventions.md) (the binding contract).
> **Iteration budget:** 5.

## Why this slice first

Backquote is where we've already been bitten twice (M9: lists-only, then typed-only).
It's also the cleanest piece to port (a pure tree transform). And the *recursion
skeleton* + **run-over-all-forms** change is the structural fix for the root problem (the
driver runs no `lfe_macro`, so passed-through forms never get expanded). Landing this
retires `qq_expand` and makes quasiquote work uniformly in typed AND plain forms.

## In scope

- **Faithful `exp_backquote` port** — match LFE's `exp_backquote/2` (nested backquote,
  `comma`, `comma-at` splicing into **lists, tuples, and maps**, the cons/append
  optimizers). Output must match the M9.1 `backquote.expanded` golden.
- **Core-form structural recursion** — port the `exp_form` cascade enough that expansion
  descends into `case`/`let`/`lambda`/`match-lambda`/`progn`/`if`/`try`/`receive`/
  comprehensions, so a macro nested anywhere expands. Validated via the `core-forms`
  golden entries whose nested macro is backquote/core (predef macros are M9.3).
- **Run expansion over ALL emitted forms** — apply the expander to every form handed to
  `lfe_codegen` (plain passthrough `defun`/`case` AND typed-form bodies), not just
  `tf.body`. This **fixes the fully-plain-`defun` quasiquote gap** noted at M9 close.
- **Retire `qq_expand`** — remove the ad-hoc backquote/tuple code; the faithful port
  replaces it.
- **Rust↔golden diff harness** — implement the diff mechanism documented in O-6/the
  conventions doc (Rust emits EETF → Erlang harness re-reads → `prettyprint1` → compare
  with golden). Get `backquote.expanded` (and the in-scope `core-forms` entries) green
  **via the Rust expander**, not just the oracle.
- **Full M0–M9 + M9.1 regression** — existing fixtures still compile+run under the new
  expander; standing discipline.

## Out of scope (→ M9.3)

- The static `exp_predef` table (`c*r`, `let*`, `cond`, `do`, `fun`, `?`, comparison
  aliases, CL `def*` lowering, `MODULE`/`LINE`, colon sugar) and `defrecord`/`defstruct`
  generation — M9.3. (So `predef-macros.expanded` / `defrecord.expanded` and any
  `core-forms` entry whose nested macro is a predef won't fully match until M9.3 — that's
  expected; M9.2's gate is the backquote golden + recursion.)
- Tier 2 (eval-time user macros) / Tier 3 (includes/QLC/imported) — future, delegated.

## Definition of done

A faithful Rust `exp_backquote` whose output matches `backquote.expanded` via the
Rust↔golden harness; core-form recursion reaches nested backquotes (in-scope `core-forms`
entries green); expansion runs over ALL emitted forms (the fully-plain-`defun`/`case`
quasiquote case compiles+runs — Duncan's M9 example, exact); `qq_expand` removed; full
M0–M9+M9.1 regression green; `make check` clean.
