  guards.rs and validators.rs, then `proplists:get_value` → `maps:get` in all
  CT tests, worked on the first try with zero test failures.
- **One error shape for both faces** — guards and validators now share the same
  map structure, which makes the render helper (when wired) work identically for
  both the crash and return paths.
